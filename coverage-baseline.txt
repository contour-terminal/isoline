# Isoline's coverage ratchet: per file under src/isoline/, the line and branch coverage (in %) that
# the tests reach, which scripts/coverage-check.py holds every change to. Raise an entry with
# `scripts/coverage-check.py <coverage.json> coverage-baseline.txt --update`; it never lowers one.
#
# Every source line a test can reach is covered. The `exclude` lines are the exceptions, each the
# marker that names its lines in the source (`// uncovered(<marker>)`, or an uncovered-begin/-end
# range) and why no valid input reaches them; the checker holds the uncovered lines to exactly
# these. They are failed preconditions (a Require or core::todo that a validated module never
# trips), and the Tag cases of ExternKind, which Wasm 2.0 has no use for.
#

# runtime/Segment.hpp (100 % covered): four covered branches left the file, and its ten uncovered ones, the contract checks and Tag
# cases the exclusions name, are now a larger share of fewer. No branch lost its coverage.
#
# src/isoline/binary/Module.hpp's branch entry was lowered from 73.68 to 72.41 when v128LiteralOf arrived: its precondition, that the
# instruction is a v128.const or an i8x16.shuffle, adds the branch of both comparisons failing, which no valid caller takes, as
# every Require's failing side is. No branch lost its coverage.
#

# precondition, that a scalar float operator or trunc_sat lifted to a lane did not trap, adds the branch of a trap, which none of
# them takes, as every Require's failing side is. No branch lost its coverage.

# from 98.60 to 98.55, when memory64 moved copyCountType and the address-type reaches into binary/Types.hpp (copyCountType,

# below, are now a larger share of fewer. No line lost its coverage.
