# The functions that keep Require() (scripts/check-contract-spelling.py; docs/language-features.md).
#
# A check in a function that may throw cannot be a contract: a throwing violation handler's exception
# would let the caller go on past it. Each such function is a row:
#     file (under src/isoline/) | function | count | reason
# The reasons: "allocates (std::bad_alloc reaches the P17 boundary)" (it allocates);
# "calls a function that may throw" (it calls one that is not noexcept); "a throwing interface" (it is not declared
# noexcept, a lambda or a virtual override among them, though what it calls may not throw). A check in a
# lambda is its enclosing function's. The rows were made by spelling every check as a contract and
# building the native lane: its static_assert named each function below.
